# Песочница тестов-доказательств (D5)

Нода «Тест-доказательство (песочница)» (`proof.sandbox`, `backend/analyzers/sast/.../ProofNode.kt`) строит для SAST-находок тесты MockMvc и запускает их **только здесь**, в контейнере:

- `--network none`, `--cap-drop ALL`, `no-new-privileges`, пользователь без root (`sandbox`, uid 10001);
- лимиты: 2 CPU, 3 ГБ памяти, 512 процессов, таймаут (по умолчанию 300 с, параметр ноды);
- проект смонтирован только для чтения и копируется во временную папку контейнера; результаты — в отдельную папку запуска.

Нет Docker — нода отвечает «песочница недоступна», на хосте чужой код не исполняется.

Подготовка (один раз, нужна сеть — скачать зависимости проекта в кэш Gradle):

```bash
bash tools/sandbox/warm.sh                      # учебный проект
bash tools/sandbox/warm.sh <путь к проекту>     # другой проект перед проверкой
```

Статусы: `REPRODUCED` — тест прошёл, уязвимость воспроизводится; `NOT_REPRODUCED` — тест упал (защита сработала); `ERROR` — не собралось; `TIMEOUT`; `NOT_SUPPORTED` — для класса или маршрута нет шаблона. Итог привязан к хэшу файлов проекта (`projectHash`).

Шаблоны: `route-authorization` — запрос без входа к маршруту, который затеняет более строгое правило; `object-authorization` — владелец одной записи читает чужую по идентификатору (данные из `data.sql`); `sql-injection` — обычное значение не находит строк, `' OR '1'='1` возвращает чужие.
