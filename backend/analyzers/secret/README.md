# Поиск секретов

Нода `analyzer.secret` получает общую модель из порта `model` и возвращает список находок в порте `findings`. Она проверяет Kotlin, Gradle Kotlin DSL, YAML, properties, `.env` и строковые значения в секции `[versions]` файла `libs.versions.toml`. Правила выявляют встроенные пароли и ключи API, токены в конфигурации, литеральные значения по умолчанию и токены, составленные из констант. Параметр `minSeverity` фильтрует результат. Тесты, документация, плейсхолдеры и безопасные ссылки на окружение исключаются из находок. Литеральные секреты из тестов видны в разделе «Обратите внимание».

Нода `analyzer.secret.regex` принимает параметр `pattern` в синтаксисе RE2/J. Совпадения ищутся построчно. Лимиты составляют 1024 символа для шаблона, 16 384 символа для строки, 1000 совпадений и примерно одну секунду для поиска. При неполном обходе нода возвращает `PARTIAL`. Шаблон хранится как секретный параметр.

В отчёты поступают маска, отпечаток находки и места в исходниках. Значения остаются внутри анализатора. Для проверки на Service Desk запустите `:backend:analyzers:test`. Чтобы также получить JSON для evaluator, укажите путь записи в переменной `C4_EVALUATOR_REPORT`.
