# CORS: происхождение объекта и последнее присваивание

- Находка: `CustomerCors.kt:21–22`. Полученный из фабрики объект разрешает любой origin с credentials, зарегистрирован для приватной сводки; Spring Security CORS и сессионный вход включены.
- Контроль: `CustomerCors.kt:26–27`. Wildcard заменён доверенным origin на строке 28 до регистрации конфигурации.
- Причина FN: `CredentialedCorsRule` привязывает сканирование к синтаксическому вызову конструктора CorsConfiguration; возвращаемый фабрикой объект не отслеживается.
- Причина FP: `scan` запоминает первое опасное присваивание и не учитывает последующее безопасное значение.
