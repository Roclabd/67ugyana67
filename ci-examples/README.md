# ci-examples
Готовые конфигурации GitHub Actions и GitLab CI для пользователей платформы: шаг вызывает `/api/ci/workflows/{id}/run?wait=true` и падает при critical или неполном анализе.

В `CI_RULES_VERSION` перечислите ожидаемые версии всех анализаторов через `+`, например `codeguard-rules-v2+sast-1`. Порядок версий в настройке и в необязательном поле `rulesVersion` запроса произвольный. Шаблоны отправляют подпись полной проверки. Для другого набора нод укажите подпись его отчёта в серверном `CI_RULES_VERSION` и одноимённой переменной проекта CI. Сервер сверяет обе настройки, версии фактически запущенных анализаторов и подпись в отчёте.
